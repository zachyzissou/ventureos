OpenClaw Dashboard

This dashboard is protected by a pre-shared API token. Enter the token to start a browser session.

Where do I find the token?
On the machine running the dashboard, the token is stored at openclaw-dashboard/data/.api-token (0600 permissions). You can also set DASHBOARD_API_TOKEN in the server environment.
The token is never embedded into dashboard HTML or exposed to JavaScript. The server sets an HttpOnly cookie after successful login.
