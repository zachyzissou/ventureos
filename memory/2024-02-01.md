# Learning Journal: Plane MCP Server Configuration

## Critical Insights from Troubleshooting

### MCP Server Configuration Failures
- **Base URL Problem**: 
  * Incorrect: Appending `/api`
  * Correct: Use root host URL
  * Impact: Prevents 404 errors

- **Transport Expectations**:
  * Incorrect: HTTP-style requests
  * Correct: Newline-delimited JSON-RPC
  * Requires specialized MCP client

### Environment Variable Requirements
- Mandatory for stdio:
  * `PLANE_API_KEY`
  * `PLANE_WORKSPACE_SLUG`
  * `PLANE_BASE_URL` (root host only)

### Docker Deployment
- **Critical Finding**: 
  * Use `docker-compose.yaml`, NOT `docker-compose.yml`
  * Always specify env file explicitly

## Lessons in Technical Troubleshooting
1. Trust official documentation
2. Be precise in configuration
3. Understand protocol-specific nuances
4. Avoid over-complication
5. Systematic, step-by-step verification
